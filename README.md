# קידומן בדפדפן

- פותחים ספר או מראה מקום בעברית מספריא. הקריאה מתחילה מיד כשהטקסט זמין.
- בלימוד היומי אפשר לבחור תאריך ומסלול ולסמן סיום.
- הסידור מציג את תוכן העניינים של ספריא בנוסחי אשכנז, ספרד ועדות המזרח.
- הכפתור ״שמירה לקריאה בלי אינטרנט״ שומר את הקטע הנוכחי. ב״ספרים שלי״ אפשר לפתוח קטעים שמורים וקובצי טקסט אישיים. השמירה מקומית לדפדפן.
- בהגדרות אפשר לבחור תצוגה, גודל טקסט ולוח ישראל או חוץ לארץ. בחיבור לקידומן משתמשים בקוד ייעודי ממסך סנכרון הקריאה בטלפון.

סנכרון מעביר סיום לימוד ומיקומי קריאה של מסלולים התואמים למקור באנדרואיד. במסלולי פרשת השבוע והפטרה מיקום הקריאה נשמר באתר. בספרים אישיים הסנכרון אפשרי כשאותו הטקסט נמצא בשני הצדדים. טקסטים אישיים נשמרים בדפדפן.

## פריסה ב־GitHub Pages

1. העתיקו את הקבצים מתוך תיקיית `web` למיקום שממנו GitHub Pages יפרסם את האתר, לדוגמה לשורש המאגר החדש.
2. בהגדרות המאגר הפעילו GitHub Pages מהענף `main` ומהתיקייה המתאימה.
3. פתחו את כתובת Pages, פתחו ספר ובדקו שמירה בלי אינטרנט. לצימוד השתמשו בקוד סנכרון קריאה מהמכשיר.

אין שלב בנייה. הנתיבים יחסיים, ולכן האתר עובד גם בכתובת Pages עם שם המאגר. כתובת ה־Worker הציבורית נמצאת ב־`sync.mjs`. קוד הצימוד משמש פעם אחת ואסימון הדפדפן נשמר מקומית.

להרצה מקומית משורש המאגר הפעילו `python3 -m http.server 8765 --directory web` ופתחו `http://localhost:8765`.
